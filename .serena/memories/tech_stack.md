# Tech Stack

- Python 3.12+ (Windows primary development OS).
- Frameworks & Libraries:
  - Web: Flask, Flask-CORS.
  - Desktop GUI: CustomTkinter, PIL, Tkinter.
  - Machine Learning & Deep Learning: TensorFlow / Keras (CNN models), scikit-learn (vectorizer, encoders), numpy.
  - Computer Vision: OpenCV (`cv2`).
  - Audio & Speech: Librosa, sounddevice, Vosk (`vosk-model-small-en-us-0.15`), pyttsx3 (TTS via isolated subprocess).
  - LLM: Ollama local instance running Phi-3 Mini (`phi3`).
  - Security & Encryption: `cryptography` (Fernet symmetric encryption for patient session logs).
